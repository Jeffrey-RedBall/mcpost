# mcidea，把靈感丟進 MakeClass

使用者在寫程式或討論時冒出一個點子，不想打斷手邊的事。`/mcidea` 後面接靈感，一句話存進去，之後在網頁「知識庫 → 💡 靈感」、LINE 問「我有哪些靈感」都找得到，跟 LINE 打「靈感：」是同一個地方。

## 步驟

1. 取使用者在 `/mcidea` 後面的內容當靈感。**原文照存，不要改寫、不要潤飾、不要補充你的想法。** 後面沒內容就問一句「要存什麼靈感？」，不要自己從上下文猜一個。
2. 使用者有明講專案才帶 `project`（例如「/mcidea 專案：LINE 機器人 客戶需求要自動分類」）；沒講就不帶，不要自己歸類。
3. 存：
   ```bash
   mcpost call save_idea '{"text":"<靈感原文>","project":"<專案，沒有就不要這個欄位>"}'
   ```
   文字裡有引號或換行，要正確跳脫成 JSON。
4. 回報**一行**：「已存進靈感存放區（只有你看得到）：<標題>」＋連結。
5. 回傳 `error`：
   - 說含金鑰或密碼 → 轉述原因，請使用者移除後再存，**不要自己幫他改內容重送**
   - 太長 → 請使用者縮短或分成幾則
   - 沒有權限 → 說明權杖需要「發表內容」權限，請他到設定頁重新產生

## 不要做

- 不要存使用者沒叫你存的內容（不要因為對話裡出現一個點子就自己存）。
- 不要發布、不要公開，也沒有這個選項：靈感預設且只能是私人。
- 要把靈感做成文章或簡報，是之後在網頁用「轉成」做的，不在這裡。
